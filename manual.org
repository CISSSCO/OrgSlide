* Executive Introduction to OrgSlide
Welcome to *OrgSlide*, the high-performance presentation engine and continuous document reader designed specifically for GNU Emacs Org-mode documents!

OrgSlide eliminates the pain and friction of traditional slide software by transforming plain-text Org files directly into interactive, beautifully styled slide decks, academic papers, and continuous books.

It runs 100% in your web browser with zero server dependencies, no compilation build steps, and complete offline capability.

* The Philosophy of Plain-Text Presentations
Traditional presentation software locks knowledge into proprietary binary formats. OrgSlide is built on the philosophy that plain text is the superior format for technical communication:

- *Version Control*: Store presentations in Git alongside your code; track diffs line-by-line.
- *Speed of Thought*: Type ideas quickly in Org-mode without mouse gymnastics or pixel-nudging.
- *Longevity*: Plain text never goes obsolete and will remain readable decades from now.
- *Device Independence*: Edit on any operating system, phone, terminal, or editor.

* Core Architecture of the Org-Mode Engine
OrgSlide uses a modern, client-side compilation pipeline:

- *Parser Layer*: Scans `.org` text line-by-line, parsing metadata, drawers, heading trees, code blocks, tables, and links.
- *Data Normalizer*: Emits structured JavaScript slide objects containing hierarchy levels and breadcrumbs.
- *Render Engine*: Renders interactive PowerPoint DOM slides, applies syntax highlighting, and configures image handlers.
- *Export Matrix*: Emits standalone PDF, PPTX, Word, and single-file HTML distributions.

* Quickstart Guide: Writing Your First Org Deck
Creating an OrgSlide presentation is simple and intuitive:

1. Create a plain-text file named =presentation.org=.
2. Define document metadata at the top:
   =#+TITLE: My Presentation=
   =#+AUTHOR: Your Name=
3. Add Level 1 headings using asterisks to define slides:
   =* Slide 1 Title=
   =Here is the content of slide 1.=
   =* Slide 2 Title=
   =Here is the content of slide 2.=
4. Drag and drop the file onto OrgSlide or upload it via the main menu!

* Document Metadata Headers
Configure global document properties at the very top of your Org file:

- =#+TITLE: Main Presentation Title= — Prominently displayed on Slide 1.
- =#+SUBTITLE: Secondary Subtitle= — Rendered beneath the main title in secondary blue.
- =#+AUTHOR: Presenter Name= — Displayed on the title slide and exported metadata.
- =#+DATE: YYYY-MM-DD= — Displayed on the title slide.
- =#+END_MESSAGE: Custom Closing Message= — Headline on the final thank-you slide.

* Heading Hierarchy & Slide Generation
OrgSlide automatically generates and numbers slides based on your heading structure:

- =* Heading (Level 1)=: Creates a primary slide or major section slide.
- =** Subheading (Level 2)=: Creates an in-depth topic slide inside the active section.
- =*** Sub-subheading (Level 3)=: Creates a focused child slide with full breadcrumbs.

Every slide features dynamic breadcrumbs in the upper-left, keeping your audience anchored in your presentation outline.

* Navigation Breadcrumbs & Clickable Hierarchy
Notice the breadcrumbs above the slide title:
=TITLE ❯ CHAPTER ❯ SLIDE=

Every breadcrumb button is clickable:
- Click the document title to jump back to Slide 1.
- Click a parent chapter to jump to the start of that topic.
- Use during Q&A sessions to seamlessly navigate your deck.

* Text Formatting & Inline Markup
Format plain text with instant visual hierarchy using standard Org markup:

- *Bold*: Wrap text in asterisks like =*bold concept*=.
- =Verbatim / Code=: Wrap text in equals signs like ==variable_name==.
- ~Code Snippets~: Wrap text in tildes like =~npm run build~=.
- *Inline Code*: Monospace font highlights commands and keywords cleanly.
- Standard Paragraphs: Plain text lines automatically flow with balanced line heights and theme contrast.

* Source Code Blocks: Syntax Highlighting
Write multi-language source code blocks using =#+begin_src= and =#+end_src=:

#+begin_src python

async function fetchPresentationData(docPath) {

* Export Ecosystem: 1-Click PDF Generation
Export your slides to publication-quality PDF:

1. Click the *Export* button or press *Ctrl + P*.
2. OrgSlide's print stylesheet formats every slide into a distinct landscape page.
3. Select *Save as PDF*, set Margins to *None*, and check *Background Graphics*.

* Folder Manager & IndexedDB Asset Bundling
Present local diagrams and images completely offline:

1. Click *Upload Folder* on the main menu.
2. Select your presentation folder containing `.org` files and images.
3. OrgSlide stores all files in an isolated **IndexedDB** database in your browser.
4. Relative image paths (e.g., `./images/diag.png`) resolve automatically!

* Offline Resilience & Browser Storage
OrgSlide guarantees that you never lose your presentation:

- Current document text is stored in `sessionStorage` and `localStorage`.
- Current slide index is preserved in the URL hash (`#1`, `#5`).
- Refreshing your browser immediately restores your exact slide and presentation state!

* Clearing Session Storage: Clean Slate Feature
Need to clear your browser session and return to the main menu?

- Click the red *Clear Session* button on the landing page.
- Purges cached drafts, resets the URL hash, and resets presenter states.
- Ensures refreshing lands cleanly on the main menu for a new presentation!
