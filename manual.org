* Introduction to OrgSlide
Welcome to *OrgSlide*, the modern presentation engine and continuous document reader built natively for Emacs Org-mode documents!

OrgSlide eliminates the pain and friction of traditional presentation software by transforming plain-text Org files directly into interactive, beautifully styled slide decks, academic papers, and continuous books—running 100% in your web browser with zero server dependencies or build steps.

This entire manual is an Org-mode file rendered live by OrgSlide.

* Org-Mode Syntax Fundamentals
Writing presentations in OrgSlide is intuitive and adheres to standard Org-mode markup conventions.

** Document Header Metadata
Place metadata at the very beginning of your file to configure global presentation properties:
- =#+TITLE: Main Presentation Title= — Displayed prominently on the title slide.
- =#+SUBTITLE: Descriptive Subtitle= — Renders below the title.
- =#+AUTHOR: Presenter Name= — Displayed on the title slide and exported metadata.
- =#+DATE: YYYY-MM-DD= — Displayed on the title slide.

** Heading Depth & Slide Generation
OrgSlide automatically generates and numbers slides based on your heading structure:
- =* Heading (Level 1)=: Creates a primary slide or major section slide.
- =** Subheading (Level 2)=: Creates an in-depth topic slide inside the active section.
- =*** Sub-subheading (Level 3)=: Creates a focused child slide with full breadcrumb tracking.

Dynamic breadcrumbs are shown in the upper-left of every slide so your audience always knows where they are in the presentation hierarchy.

* Working with Links & Social Profiles
Links in OrgSlide connect your slides to the web and allow customized presenter attribution.

** Hyperlinks in Body Text
Use standard Org bracket syntax to create links:
- *Text Links*: =[[https://github.com][Visit GitHub]]= renders as [[https://github.com][Visit GitHub]].
- *Direct URLs*: Enclosing naked web addresses inside brackets generates clickable hyperlinks.
- *Linked Images*: Enclose an image URL inside a link =[[https://github.com][https://avatar.png]]= to create a clickable image card!

** Presenter Social Links & Profile Editor (Alt + E)
Press *Alt + E* anytime during a presentation to open the *Profile & Social Links Modal*:
- Customize your *GitHub*, *Portfolio*, *Repository*, and *LinkedIn* links.
- Type =NA= in any field to hide that icon from the footer and end slide.
- Custom links persist in browser storage and dynamically populate the bottom-left footer icons across all slides!

** Interactive Hover Control Dock
Hover your mouse over any image on a slide to reveal the floating control dock:
1. *4 Alignment Modes*: Left (float left, text wraps right), Center (block center), Middle (inline centered), and Right (float right, text wraps left).
2. *Fine Sizing (-15% / +15%)*: Scale images up or down in smooth 15% increments.
3. *Width Presets (100% / 1:1)*: Snap to full slide width (=100%=) or reset to native image dimensions (=1:1=).
4. *Free Move & 8-Way Resize*: Drag the image anywhere on the slide canvas and resize using 8 directional bounding-box handles.
5. *Position Lock*: Click the padlock icon to lock the position and dimensions permanently.
6. *Refresh Persistence*: All custom image moves, scales, and alignments are automatically saved to your browser storage and restored upon page reload!

** How to Upload a Folder
1. On the landing menu or top toolbar, click *Upload Folder*.
2. Select any folder on your computer containing your =.org= presentation and images.
3. OrgSlide reads all files and stores them securely in browser *IndexedDB* storage for the entire session.

** Automatic Relative Path Resolution
If your document references local paths like =[[./images/architecture.png]]= or =[[chart.jpg]]=, OrgSlide automatically matches the filename to assets in your uploaded folder and displays them without any manual configuration!

** Workspace Explorer Modal
Click *View Uploaded Folder* or the folder icon in top controls to view all files, copy relative links, or inspect asset dimensions.

* Interactive Code Blocks
Code blocks in OrgSlide are designed for technical walk-throughs and live demos. Wrap code inside =#+begin_src= and =#+end_src=.

#+begin_src python
import math

def calculate_fibonacci(n):
    """Generates the Fibonacci sequence up to n terms."""
    sequence = [0, 1]
    while len(sequence) < n:
        sequence.append(sequence[-1] + sequence[-2])
    return sequence[:n]

print(calculate_fibonacci(8))
#+end_src

#+RESULTS:
: [0, 1, 1, 2, 3, 5, 8, 13]

* 7 Dynamic Render Layouts (Alt + M)
Press *Alt + M* or click the layout icon in the top toolbar to switch between 7 distinct presentation layouts:

1. *Presentation Slide*: The default 16:9 widescreen presentation layout optimized for projectors, conference screens, and slide talks.
2. *LaTeX Beamer*: Formal academic presentation style with persistent top navigation headers and structured slide framing.
3. *Book / Continuous Article*: An elegant, continuous-scroll layout with classic serif typography, ideal for reading documentation or long papers.
4. *Hierarchical Outline*: Minimalist, tree-structured document flow emphasizing heading organization.
5. *Computational Notebook*: Jupyter-style linear cell format ideal for technical walk-throughs and code review sessions.
6. *Scientific IEEE Paper*: Classic two-column academic research paper format with formal typography and dense technical layout.
7. *Retro Terminal*: Developer-focused phosphor green-on-black terminal aesthetic featuring monospaced typography.

* Navigation & Slide Visibility (Alt + .)
Navigating complex decks is instantaneous with the interactive Tree View.

** Hierarchical Table of Contents
Press *Alt + .* or click the list icon to open the Table of Contents:
- Jump to any slide with a single click.
- Zoom the navigation tree in or out using =+= and =-= keys.

** Slide Visibility Toggles (Hiding Slides)
Every slide entry in the Tree View features a visibility checkbox:
- *Tailor Your Presentation*: Uncheck slides you wish to omit for shorter talks or specific audiences.
- *Seamless Navigation*: Hidden slides are skipped automatically when using keyboard navigation keys.
- *Clean Continuous Reading*: Hidden slides are completely suppressed in Book, Paper, and Outline render layouts.

* Rapid Slide Jump (Alt + G & Click Counter)
Navigating directly to a specific slide is fast and intuitive:

1. *Click Slide Numbering*: Click the slide counter in the bottom-right footer (e.g., =Slide 15 of 32=) to open the *Go to Slide* dialogue.
2. *Keyboard Shortcut*: Press *Alt + G* anywhere in the presentation.
3. *Quick Jump*: Enter the target slide number and press =Enter= or click *Go* to jump immediately. Press =Esc= to cancel.

* Universal Multi-Format Export Engine
Click the Export icon in the top navigation toolbar to export your presentation into universal formats for colleagues and clients:

1. *Standalone Interactive HTML*: Downloads a self-contained single-file HTML application containing your presentation, styles, and full interactive engine for offline viewing.
2. *Microsoft PowerPoint (.pptx)*: Converts slides into native PowerPoint presentation format with full graphical fidelity.
3. *Word Document (.doc)*: Generates a structured document compatible with Microsoft Word, LibreOffice, and Google Docs with embedded code and tables.
4. *Printable PDF*: Produces a clean 16:9 PDF document formatted for printing and distribution.

* Session Persistence & Landing Page
OrgSlide protects your work and presentation state across browser sessions:

- *Landing Page Recent Documents*: The home menu automatically saves your 10 most recently opened documents with title previews, slide counts, and open timestamps for quick 1-click reloading.
- *Active Slide Memory*: Refreshing the page maintains your exact active slide via URL hash anchors (e.g., =#12=) and session storage.
- *Clean Re-Upload Reset*: Uploading a new document automatically resets your view to Slide 1 and clears previous image overrides for a pristine presentation start.
- *Full Theme Compatibility*: The landing home menu dynamically reflects whichever color theme is selected in the theme engine.
